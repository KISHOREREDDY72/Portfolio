## 🛠️ Built With
* **HTML5:** Semantic structure and layout.
* **CSS3:** Custom styling, glassmorphism UI design, flexbox/grid, and smooth scroll animations.
* **Vanilla JavaScript:** Modal popups, smooth navigation, and intersection observer animations.
* **EmailJS:** Integrated automated contact form that securely forwards messages and sends auto-replies without backend servers.

## 🌟 Key Features
* **Glassmorphism Design:** A premium, translucent UI that complements the dark technology background.
* **Fully Responsive:** Adapts seamlessly to desktop, tablet, and mobile displays.
* **Interactive Modals:** Detailed project information that opens in smooth, floating popups.
* **Automated Contact System:** Visitors can send messages directly from the site and immediately receive a personalized "Thank You" confirmation email.
* **One-Click Resume:** Easily accessible downloadable PDF resume.

## 👨‍💻 About Me
I am a Detail-oriented QA Engineer specializing in manual and automated testing of web applications using Java and Selenium. I have a proven track record in enhancing test coverage and accelerating defect resolution through efficient Jira management.
